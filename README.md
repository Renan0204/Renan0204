Sobre mim

Sou Desenvolvedor Java Backend Júnior, atualmente no último período de Sistemas para Internet, com experiência profissional em desenvolvimento web, integrações e automações.

Minha trajetória com tecnologia começou ainda na adolescência. Aos 16 anos iniciei um curso profissionalizante de informática e, por incentivo de um professor, tive contato com programação e percebi que queria seguir profissionalmente na área.

Hoje atuo com React, TypeScript e Tailwind CSS no desenvolvimento de aplicações web e também desenvolvo projetos voltados ao backend utilizando Java, Spring Boot, APIs REST e PostgreSQL.

Tenho maior interesse em Backend, Banco de Dados, Inteligência Artificial e Cibersegurança, buscando sempre entender não apenas como fazer, mas também por que uma solução funciona.

Atualmente focado em

Java & Spring Boot       -> desenvolvimento backend e APIs REST
PostgreSQL & SQL         -> modelagem e persistência de dados
JWT & Segurança          -> autenticação e controle de acesso
React & TypeScript       -> interfaces e integração com backend
IA & n8n                 -> automações e otimização de processos
Docker                   -> ambientes e aplicações containerizadas
